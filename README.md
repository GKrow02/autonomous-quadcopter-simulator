# Autonomous Quadcopter Flight Simulator

A Python-based quadcopter flight simulator developed to better understand flight dynamics, control systems, and autonomous navigation. This project models a quadcopter's motion and uses PID controllers to autonomously navigate through a series of waypoints.

## Features

- Physics-based quadcopter simulation
- Position and velocity modeling
- Roll, pitch, and yaw dynamics
- PID flight controller
- Autonomous waypoint navigation
- Flight path visualization
- Adjustable controller gains for tuning

## Motivation

I started this project to bridge the gap between aerospace engineering theory and practical implementation. Rather than only learning how control systems work in class, I wanted to build my own simulator and understand how flight dynamics, feedback control, and autonomous navigation work together.

## Future Development

This project is actively being expanded. Planned improvements include:

- PX4 flight controller integration
- Autonomous obstacle avoidance
- Sensor modeling (IMU, GPS, etc.)
- Wind and disturbance modeling
- Improved flight dynamics
- Custom UAV airframe designed in SolidWorks
- Implementation on a real autonomous quadcopter

## Technologies Used

- Python

- Matplotlib

This project is under active development. New features and improvements will continue to be added as I expand the simulator and transition toward real autonomous UAV hardware.
